# Clínica Brugal Mejía López — Project Documentation

This folder is the source of truth for the branding, institutional research, content strategy, and web implementation of Melosa Clínica Brugal.

## Purpose

The project does not start from a blank brand. Melosa Clínica Brugal already has a recognized name, a blue-and-white visual identity, a historical seal, a long relationship with Puerto Plata, an existing philosophy, and a broad clinical offering. The work documented here organizes those assets, separates verified facts from provisional claims, and translates the existing identity into a consistent digital system.

## Documentation map

- `brand/brand-foundation.md` — brand identity, positioning, narrative, personality, naming, voice, claims, and architecture.
- `brand/design-system.md` — color, typography, spacing, accessibility, UI foundations, imagery, and reusable visual rules.
- `research/institutional-research.md` — reconstructed institutional history, services, public evidence, notable medical milestones, and unresolved historical questions.
- `content/web-content-strategy.md` — information architecture, page hierarchy, patient tasks, SEO content model, and editorial rules.
- `web/implementation-brief.md` — developer handoff, components, performance, accessibility, structured data, analytics, and implementation constraints.
- `sources/source-registry.md` — public sources used during research and the intended use of each source.
- `open-questions.md` — information that must be confirmed directly with the client before final publication.
- `mockups/brand-mockup-v2.html` — current interactive HTML brand/design-system mockup.

## Core direction

The central brand territory is:

> **A historic medical institution of Puerto Plata that continues to evolve with medicine.**

The digital identity must communicate two ideas at the same time:

> **We have cared for generations.**

and

> **We continue to advance with medicine.**

## Status model

Every important institutional fact should eventually be classified as one of:

- `verified` — safe to publish based on approved or reliable current evidence.
- `needs_review` — plausible or publicly stated, but requires direct institutional confirmation.
- `historical` — supported as historical context but not necessarily current operational information.
- `deprecated` — old, conflicting, superseded, or explicitly rejected information.

This distinction is especially important for doctors, schedules, insurance coverage, service availability, historical dates, and superlative marketing claims.

## Current critical caution

The existing public website contains conflicting foundation dates, including references to 1936 and 1973. Independent historical material better supports a clinical association in the 1940s and the creation of Dr. Francisco “Panchito” Brugal's own clinic in 1952. Do not publish a definitive founding year until documentary evidence from the institution resolves the conflict.

- Existing tagline: **Cuidarte es amarte.**
- Geographic anchor: **Puerto Plata, República Dominicana**
- Primary visual territory: **blue + white**
- Primary archetype: **Caregiver**
- Secondary archetype: **Sage**

## Working principle

The website must first help a patient complete a task:

1. Find a doctor.
2. Find a specialty or service.
3. Book an appointment.
4. Contact emergency care.
5. Find the clinic and get directions.

History, brand storytelling, institutional news, and educational content support trust, but they must not block these primary tasks.
